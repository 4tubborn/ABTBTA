# Another Better Than Better Than Adventure

Now BTA is better than ever!

1. **Classic armor protection is back!** No more worrying about balancing damage reduction across different damage types.
2. **The classic armor bar has returned!** Familiar and reliable, just like the good old days. :sensor_eyebrow:
3. **Activators now work more like dispensers!** They randomly select an occupied slot and use the item in that slot.
4. **Classic bed recipes are back!** No more fighting zombies just to skip the night!

Even better with customization! Many of these features can be toggled through the in-game Options menu.
